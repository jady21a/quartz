# Syncing with git

```bash

../   //回到上一层目录
```

## Sync to GitHub
1. Create a new repo on GitHub — don't check README / .gitignore (we create those locally) — and get the repo's SSH URL.
2. Enter your local project directory
Initialize the repo
```bash
git init
```
Create `.gitignore`
```
touch .gitignore
```
Common things to ignore for an Obsidian plugin
```bash
node_modules/
dist/
.obsidian/
.DS_Store
```

3. First commit
Check the current status
```bash
git status
```
Stage all files
```bash
git add .
```
Commit
```bash
git commit -m "init: first commit"
```
4. Push the local code to GitHub
Bind the remote repo
```bash
git remote add origin ssh-url
```
Double-check (optional)
```bash
git remote -v
```
Push to GitHub
	Rename the local branch (GitHub's default branch is `main`; rename your local branch to `main` so the sync works — you can check the name with `git branch`)
```bash
git branch -M main
```
Push the branch to GitHub and set up tracking
```bash
git push -u origin main
```


5. Day-to-day push flow
Stage
```bash
git add .
```
Commit message
```bash
git commit -m 
```
Sync
```bash
git push
```

Force-overwrite the remote repo
```bash
git push -f
```


6. Commit message conventions
```text
feat: 新功能
fix: 修 bug
refactor: 重构
docs: 文档
style: 只改格式
```


## Rolling back a git version
View the commit history
```bash
git log --oneline
```
Roll back HEAD while keeping your working-tree changes
```bash
git reset --soft <commit_hash>
```

Undo the rollback
Find the commit you had before the rollback
```bash
git reflog
```
Point HEAD back to the original commit
```bash
git reset --soft original-hash
```


### Don't roll back — just dig out the old code
Check out an entire old version into some temporary place
```bash
git show d31e499:src/ui/SidebarOverviewView.ts -- “/Users/jz/Library/Mobile Documents/iCloud~md~obsidian/Documents/all-in/.obsidian/plugins/learning-system/src”
```


## Submodules
Say the plugin lives in repo A, and repo B needs to reuse A's plugin.
Set this up in repo B:


```bash
git submodule update --remote
```

```bash
git commit -am "update a-plugin"
```

```bash
git clone --recurse-submodules +A仓库的shh
```


Subsequent sync flow
```bash
git submodule update --remote
```

```bash
git commit -am "update learning-system submodule"
```

If a plugin with the same name already exists locally but isn't a submodule

```bash
rm -rf .obsidian/plugins/learning-system
```

```bash
git submodule add git@github.com:jady21a/obsidian-learning-system.git .obsidian/plugins/learning-system
```

```bash
git commit -m "add learning-system submodule under .obsidian/plugins"

```
Verify it worked
```bash
git submodule status
```
