## 同步到GitHub管理
1. 在GitHub新建一个仓库,不要勾选 README / .gitignore（我们本地建）,得到仓库的ssh地址,
2. 进入本地项目的目录
初始化仓库
```bash
git init
```
创建 `.gitignore`
```
touch .gitignore
```
常见 Obsidian 插件推荐忽略
```bash
node_modules/
dist/
.obsidian/
.DS_Store
```

3. 第一次提交代码
查看当前状态
```bash
git status
```
添加所有文件
```bash
git add .
```
提交
```bash
git commit -m "init: first commit"
```
4. 把本地代码推到 GitHub
绑定远程仓库
```bash
git remote add origin ssh地址
```
检查一下(可省略)
```bash
git remote -v
```
推送到 GitHub
	修改本地分支名(因为GitHub分支默认是main,修改本地分支为main以使同步正常,可以`git branch`检查分支名)
```bash
git branch -M main
```
把分支推到 GitHub 并建立关联
```bash
git push -u origin main
```


5. 日常推送流程
```bash
git add .
git commit -m "feat: 优化全选功能"
git push
```

6. 提交信息规范
```text
feat: 新功能
fix: 修 bug
refactor: 重构
docs: 文档
style: 只改格式
```
