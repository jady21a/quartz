## 同步到GitHub
1. 在GitHub新建一个仓库,不要勾选 README / .gitignore（我们本地建）,得到仓库的ssh地址,
2. 进入本地项目的目录
初始化仓库
```bash
git init
```
创建 `.gitignore`
```
touch .gitignore
```
常见 Obsidian 插件推荐忽略
```bash
node_modules/
dist/
.obsidian/
.DS_Store
```

3. 第一次提交代码
查看当前状态
```bash
git status
```
添加所有文件
```bash
git add .
```
提交
```bash
git commit -m "init: first commit"
```
4. 把本地代码推到 GitHub
绑定远程仓库
```bash
git remote add origin ssh地址
```
检查一下(可省略)
```bash
git remote -v
```
推送到 GitHub
	修改本地分支名(因为GitHub分支默认是main,修改本地分支为main以使同步正常,可以`git branch`检查分支名)
```bash
git branch -M main
```
把分支推到 GitHub 并建立关联
```bash
git push -u origin main
```


5. 日常推送流程
添加
```bash
git add .
```
提交备注
```bash
git commit -m 
```
同步
```bash
git push
```

强制覆盖远程仓库
```bash
git push -f
```


6. 提交信息规范
```text
feat: 新功能
fix: 修 bug
refactor: 重构
docs: 文档
style: 只改格式
```


## git 版本回退
查看历史提交
```bash
git log --oneline
```
保留工作区更改，回退 HEAD
```bash
git reset --soft <commit_hash>
```

取消版本回退
找回回退前的提交
```bash
git reflog
```
把 HEAD 指回原来的提交
```bash
git reset --soft 原来的哈希号
```

## 子模块
假设插件放于A仓库,B仓库需要复用A仓库的插件
在B仓库中设置


```bash
git submodule update --remote
```

```bash
git commit -am "update a-plugin"
```

```bash
git clone --recurse-submodules +A仓库的shh
```


后续同步流程
```bash
git submodule update --remote
```

```bash
git commit -am "update learning-system submodule"
```

如果本地已经存在同名插件,但是该文件不是submodule

```bash
rm -rf .obsidian/plugins/learning-system
```

```bash
git submodule add git@github.com:jady21a/obsidian-learning-system.git .obsidian/plugins/learning-system
```

```bash
git commit -m "add learning-system submodule under .obsidian/plugins"

```
验证是否成功
```bash
git submodule status
```
