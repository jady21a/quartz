## Obsidian 工作流模板库分享

对着空白的 Obsidian 不知道从哪下手?
我把自己日常在用的整套系统抽成了一个能直接复制的模板库——**目录、模板、Dataview、主页仪表盘都配好了**,复制下来就能跑,省去从零搭目录、配路径、踩插件坑的时间。

> [!tip] 仓库地址
> 👉 https://github.com/jady21a/obsidian-workflow-vault
>
> 点 **Code → Download ZIP** 下载,解压后用 Obsidian「Open folder as vault」打开即可。

### 里面有什么

- **10个分好工的功能区** —— 速记 / 读书观影 / 项目任务 / 待办复盘 / AI 工作流技能… 每个区都留了 1 篇示例 + 配套模板,照着填就行。
- **homepage是个控制台** —— 一键开今日笔记、新建项目、读书笔记; 还有活跃度 / 字数双热力图看输出节奏。
- **开箱即用** —— 常用插件、CSS 片段、快捷键都已内置配好,不用自己一个个找。

### 三步上手

1. **下载** 仓库 ZIP,解压;
2. 用 Obsidian **当作仓库打开**,按 README 启用核心插件;
3. 把每个区里的 **「示例」换成你自己的内容**,它就真正属于你了。

README 里写清了依赖插件、主题 CSS、快捷键和常见问题,跟着走基本不会卡。

> 这套库是我自己每天在用的系统的「示例版」,不是标准答案,而是一个**能直接跑起来的起点**。
> 别怕改:目录名、模板字段、Dataview 查询都能按你的习惯调。
> 如果你有更多想法,欢迎来评论区交流~
